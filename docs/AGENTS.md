# Reglas para Codex en esta plataforma
1. En páginas de negocio usar solo `Mx*`.
2. No exponer tipos `Mud*` en API pública salvo justificación aprobada por ADR.
3. Nuevos componentes requieren test bUnit + actualización de showcase + actualización contractual.
4. Tokens visuales se cambian en `MachSoft.DesignSystem`, nunca en app host.
