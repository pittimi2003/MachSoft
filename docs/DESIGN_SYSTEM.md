# Design System
Autoridad única de color, tipografía, espaciado, radio, elevación, foco, densidad y capas.

## Tokens
- Colores: `ColorTokens` (brand, neutrales, semánticos).
- Escalas: `ScaleTokens` (spacing, radius, elevation, typography).
- Contrato de tema: `ThemeContract` + `ThemeCatalog` (light/dark).

## Gobierno
Toda decisión visual reusable se registra aquí antes de tocar componentes.
